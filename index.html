About Xelvra

Xelvra is an Android VPN client developed by MDevz. It provides tools for creating and importing connection profiles and establishing VPN connections using the Xray networking engine.

Xelvra does not itself provide or operate VPN or proxy servers. Users supply or select the connection configuration used by the application.
